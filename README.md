# Einführung in die Programmierung für Android-Tablets mit Android Studio (2016)

👉 **Verwandter Kurs:**
[Einführung in die Programmierung für Android-Tablets mit Android Studio (2016)](https://stahe.github.io/de-android-aout-2016/)

---

## 📖 Überblick

Dieses Dokument ist eine Überarbeitung und Zusammenführung verschiedener Lernressourcen zur Android-Entwicklung. Es soll eine **schrittweise und strukturierte Einführung** in die Programmierung von Android-Anwendungen bieten, insbesondere für Tablets.

Es berücksichtigt mehrere wichtige Entwicklungen:

* Einführung von **Android Studio** als primäre Entwicklungsumgebung
* Verwendung des Build-Systems **Gradle**
* Einführung von **RxJava** zur Verwaltung asynchroner Operationen
* Fortgeschrittene Strukturierung von Android-Anwendungen (Fragmente, Lebenszyklus, Client/Server-Architektur)

Ein wesentliches Merkmal dieses Dokuments ist die Vorstellung eines **generischen Frameworks für Android-Client/Server-Anwendungen**, das in zahlreichen Projekten wiederverwendet werden kann.



---

## 🎯 Lernziele

* Verständnis der Grundlagen der Android-Entwicklung
* Beherrschung der Navigation zwischen Ansichten und Fragmenten
* Verwaltung des Lebenszyklus von Android-Komponenten
* Implementierung von Client/Server-Architekturen
* Datenbearbeitung über Benutzeroberflächen
* Einführung in die asynchrone Programmierung mit RxJava
