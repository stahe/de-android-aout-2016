    4. TP 1: Grundlegende Verwaltung einer Gehaltsabrechnung

    4.1. Introduction

    Um das bisher Gelernte anzuwenden, schlagen wir nun eine Aufgabe vor, bei der ein Android-Client für Tablets geschrieben werden soll, mit dem die Lohnabrechnungen der Mitarbeiter eines Vereins simuliert werden können.

    Die Anwendung wird eine Client-Server-Architektur aufweisen:

    • Der Server [1] wird bereitgestellt;
    • der Android-Client [2] muss erstellt werden.

    4.2. Die Datenbank

    4.2.1. Definition

    Die statischen Daten, die für die Erstellung der Gehaltsabrechnung benötigt werden, werden in einer Datenbank gespeichert, die wir im Folgenden als „ dbpam“ bezeichnen. Diese Datenbank enthält die folgenden Tabellen:

    Tabelle EMPLOYES: enthält Informationen zu den verschiedenen Tagesmüttern

    Struktur:

    ID
    Primärschlüssel
    VERSION
    Versionsnummer – erhöht sich bei jeder Änderung der Zeile
    SS
    Sozialversicherungsnummer des Mitarbeiters – eindeutig
    NOM
    Name des Mitarbeiters
    PRENOM
    sein Vorname
    ADRESSE
    seine Adresse
    VILLE
    seine Stadt
    CODEPOSTAL
    seine Postleitzahl
    INDEMNITE_ID
    Fremdschlüssel im Feld [ID] der Tabelle [INDEMNITES]

    Sein Inhalt könnte wie folgt lauten:

    Tabelle COTISATIONS: enthält die für die Berechnung der Sozialbeiträge erforderlichen Prozentsätze

    Struktur:

    ID
    Primärschlüssel
    VERSION
    Versionsnummer – erhöht sich bei jeder Änderung der Zeile
    CSGRDS
    Prozentsatz: allgemeiner Sozialbeitrag + Beitrag zur Tilgung der Sozialschuld
    CSGD
    Prozentsatz: abzugsfähiger allgemeiner Sozialbeitrag
    SECU
    Prozentsatz: Sozialversicherung, Witwenrente, Altersrente
    RETRAITE
    Prozentsatz: Zusatzrente + Arbeitslosenversicherung

    Der Inhalt könnte wie folgt lauten:

    Die Sozialversicherungsbeiträge sind unabhängig vom Arbeitnehmer. Die vorstehende Tabelle enthält nur eine Zeile.

    Tabelle INDEMNITES: enthält die Elemente, die zur Berechnung des zu zahlenden Gehalts erforderlich sind.
    ID
    Primärschlüssel
    VERSION
    Versionsnummer – erhöht sich bei jeder Änderung der Zeile
    INDICE
    Verarbeitungsindex – eindeutig
    BASEHEURE
    Nettopreis in Euro für eine Stunde Bereitschaftsdienst
    ENTRETIENJOUR
    Verpflegungszuschlag in Euro pro Betreuungs-Tag
    REPASJOUR
    Verpflegungszulage in Euro pro Betreuungs-Tag
    INDEMNITESCP
    Urlaubsgeld. Dies ist ein Prozentsatz, der auf das Grundgehalt anzuwenden ist.

    Der Inhalt könnte wie folgt lauten:

    Es ist zu beachten, dass die Zulagen von einer Tagesmutter zur anderen variieren können. Sie sind nämlich über den Gehaltsindex der jeweiligen Tagesmutter mit dieser verknüpft. So hat Frau Marie Jouveinal, die einen Gehaltsindex von 2 hat (Tabelle EMPLOYES), einen Stundenlohn von 2,1 Euro (Tabelle INDEMNITES).

    4.3. Installation des Webservers / jSON

    4.3.1. Installation

    Die Java-Binärdatei des Webservers / jSON wird Ihnen zur Verfügung gestellt:

     

    Um den Webserver / jSON zu starten, gehen Sie wie folgt vor:

    • Starten Sie SGBD MySQL;
    • stellen Sie sicher, dass die Dateien BD und [dbpam_hibernate] vorhanden sind;
    • Öffnen Sie ein DOS-Fenster;
    • wechseln Sie in den Ordner der JAR-Datei;
    • Geben Sie den folgenden Befehl ein: 
    java -jar pam-server-01-all-1.0.jar

    Dies setzt voraus, dass sich die Binärdatei [java.exe] im Verzeichnis PATH auf Ihrem Rechner befindet. Ist dies nicht der Fall, geben Sie den vollständigen Pfad zu [java.exe] ein, zum Beispiel:

    D:\Programs\devjava\java\jdk1.8\bin\java -jar pam-server-01-all-1.0.jar

import java.util.List;

public class Response<T> {

    // ----------------- Eigenschaften
    // Status der Transaktion
    private int status;
    // allfällige Statusmeldungen
    private List<String> messages;
    // der Antworttext
    private T body;

    // Konstruktoren
    public Response() {

    }

    public Response(int status, List<String> messages, T body) {
        this.status = status;
        this.messages = messages;
        this.body = body;
    }

    // Getter und Setter
...
}

    4.4. Tests des Android-Clients

    Die fertige ausführbare Binärdatei des Android-Clients wird Ihnen wie folgt bereitgestellt:

      

    Ziehen Sie die oben genannte Binärdatei [pam-client.apk] mit der Maus auf einen Tablet-Emulator [GenyMotion]. Sie wird dann gespeichert und anschließend ausgeführt. Starten Sie außerdem den Webserver / jSON, falls dies noch nicht geschehen ist. Der Android-Client dient dazu, die vom Webserver / jSON zurückgegebenen Informationen abzurufen und aufzubereiten. Der Android-Client verfügt über folgende Ansichten:

    Zunächst muss eine Verbindung zum Webdienst / jSON hergestellt werden:

    • In [1] wird die URL des Webdienstes /jSON angegeben. Geben Sie im Emulator eine der Adressen IP oder PC ein (jedoch nicht 127.0.0.1). Geben Sie auf einem Tablet die WLAN-Adresse des Webserver-Rechners / jSON ein und deaktivieren Sie die Firewall des Server-Rechners, falls vorhanden, da diese eingehende Verbindungen blockieren könnte;
    • Unter [2] stellen Sie eine Verbindung her;

    Man gelangt dann zur Simulationsseite:

    • In [3] wählen Sie einen Mitarbeiter aus;
    • In [4] gibt man eine Stundenzahl an;
    • unter [5] gibt man die Anzahl der Tage ein;
    • in [6] wird die Simulation gestartet;

    Die daraufhin angezeigte Simulationsseite sieht wie folgt aus:

    • in [7] wird die erzeugte Simulation angezeigt;
    • In [8] wird sie gespeichert;

    • in [9], die Liste der Simulationen;
    • in [10] wird eine Simulation entfernt;

    • in [11], es sind keine Simulationen mehr vorhanden;
    • in [12] kehrt man zum Simulationsformular zurück;

    • in [13] gelangt man wieder zum Formular;
    • in [14] kehrt man zur Konfigurationsseite zurück;

    • mit [15] gelangt man zurück zum ursprünglichen Anmeldeformular.
